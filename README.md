# Studio 3D

Make 3D videos in code with Claude Code: explainers, sitcoms and cinematic. There is no 3D program and no video generator. Claude writes three.js, and HyperFrames renders it frame by frame on your computer.

This repo is a skeleton: the engine, the tools and the rules. Your Claude does the rest, starting with your character.

## Start
```bash
git clone https://github.com/alisonnnfreitasss/studio-3d.git
cd studio-3d
claude
```
Then say **"open the studio"** ("abre o estúdio"). On the first run, Claude checks your computer and asks how you want your character and voice.

## What you need
Claude Code on a Claude plan. Claude checks your computer and helps you install the rest.
